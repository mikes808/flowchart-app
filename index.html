One more step: connect the database

This app needs a free Supabase project to handle sign-in and store everyone's flowcharts.

  1. Create a free project at supabase.com.
  2. Run supabase/schema.sql in the project's SQL Editor.
  3. Paste the Project URL and Publishable key into config.js in this repository.

Full instructions are in SETUP.md in the repository.
